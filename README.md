# Bond-Pricing

This Repo includes a python notebook where we price a zero coupon bond based on the Vasicek model. The Vasicek model generally serves as the theoretical framework to price zero coupon bonds. More advanced models such as the Hull-White model achieve a better approximation of a bond price and are additionally commonly used to price derivative instruments because it uses the actual term structure which the Vasicek Model does not do. However, the Vasicek model provides a solid basic understanding of bond pricing.
